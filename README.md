## Frågor

1. Skillnaden mellan git add och git commit är att **git add** lägger till en ändrad fil i "staging area", vilket är en mellanzon inann man väljer att spara. **Git commit** är istället en sparad version av projektet i det lokala repot och ska innehålla en tydlig kommentar.
2. Fördelarna med att använda branches är att det inte påverkar koden i main. Man kan samarbeta parallellt med andra utvecklare, felsöka kod eller testa nya funktioner utan att huvudkoden påverkas.
3. När man gör en merge i projektet slås den branch du är inne i ihop med huvudprojektet.
4. GitHub används för att säkert spara projekt i _molnet_, enkelt att arbeta med andra, följa arbetets struktur och historik. Att publicera direkt till Netlify betyder att projektet blir tillgängligt på internet.
5. För att exludera en fil i projektet från versionshanteringen skapar man en ny fil i rotmappen och döper till **.gitignore**. I denna listar man sedan filnamn eller mappar som ska ingoreras. Exempel på detta är känslig information så som lösenord, API-nycklar mm.
